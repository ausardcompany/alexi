## Adopted

- **Codex GPT version filter (major.minor, integer-safe)** — new
  `isSupportedCodexModel(modelId)` helper in
  `src/providers/openai/prompt-cache.ts` (plus `CODEX_MIN_MAJOR` /
  `CODEX_MIN_MINOR` constants). Ports opencode PRs #47384 (integer-major
  crash on `gpt-6`) and #47385 (comparing by major alone would misclassify
  `gpt-5.4` as `>= 5.6`). Regex is `/^gpt-(\d+)(?:\.(\d+))?/i` with the
  minor group defaulting to `0`, then a `(major, minor)` tuple compare
  against `(CODEX_MIN_MAJOR, CODEX_MIN_MINOR)`. Test coverage in
  `src/providers/openai/__tests__/prompt-cache.test.ts` under the
  `isSupportedCodexModel (opencode #47384, #47385 combined)` block.

- **GitLab AI provider reasoning-variant transform** — new
  `src/providers/gitlab.ts` module exporting `transformGitlabModel` plus the
  `RawGitlabModel` / `GitlabModel` / `GitlabReasoningFlag` types. Detects
  reasoning-capable models by id substring OR capability array entry, and
  preserves any `sapDeploymentId` routing hint verbatim so SAP AI Core
  compatibility is not compromised. Alexi has no live GitLab provider today;
  the transform ships as a forward-compatible helper so wiring GitLab into
  `src/providers/index.ts` later is a routing change only. Tests in
  `src/providers/__tests__/gitlab.test.ts`.

## Risks tracked

- **Codex filter tightening**: the new helper uses a tuple compare against
  `(CODEX_MIN_MAJOR, CODEX_MIN_MINOR) = (5, 0)`. Any SAP AI Core Codex
  deployment reporting a non-standard id shape (e.g. `openai--gpt-5` with a
  provider prefix, or a custom `gpt-4.9` deployment) would need the caller
  to strip the prefix before invoking `isSupportedCodexModel` — the helper
  anchors on `^gpt-`. Deployment inventory check recommended before wiring
  the filter into any live enumeration path.
- **GitLab provider bump**: no live GitLab consumer today, so the
  `gitlab-ai-provider@6.14.0` breaking-changes surface is not a concern for
  this sync. If GitLab is added later, re-verify the reasoning-variant
  detection against the then-current package release notes.
- **No security fixes** in this sync window — safe to defer if release
  cadence requires.
